# DailyMe — คำอธิบายโปรเจกต์

เว็บช่วยวางแผนชีวิตประจำวัน ทำด้วย HTML, CSS และ JavaScript

## ไฟล์หลัก
- `index.html` หน้าแรก
- `outfit.html` เลือกชุด
- `weather.html` ดูสภาพอากาศและคำแนะนำ
- `bag.html` เลือกของใส่กระเป๋าและทำ checklist
- `mood.html` เลือกเพลงและหนังตามอารมณ์
- `style.css` CSS ที่ใช้ร่วมกัน
- `js/main.js` ฟังก์ชันเปลี่ยนหน้า
- `js/app.js` ข้อมูลหน้าแรก
- `js/outfit-page.js` การทำงานในหน้าเลือกชุด
- `js/weather-page.js` การแสดงข้อมูลอากาศ
- `js/bag-page.js` การเลือกของและแสดงภาพของเข้ากระเป๋า
- `js/mood.js` ข้อมูลเพลง หนัง และปุ่มเล่นเพลง
- `images/` รูปภาพที่ใช้ในเว็บ
- `music/` ไฟล์เพลงที่ใช้ในเว็บ

## วิธีเปิด
เปิดโฟลเดอร์นี้ใน VS Code แล้วเปิด `index.html` ในเบราว์เซอร์  
บางฟังก์ชันที่ดึงข้อมูลจากอินเทอร์เน็ตต้องเชื่อมต่ออินเทอร์เน็ต

## หมายเหตุ
ไฟล์ JavaScript ของแต่ละหน้าถูกแยกออกจาก HTML เพื่อให้อ่านและแก้ไขง่ายขึ้น  
ถ้าจะอธิบายโปรเจกต์ในพอร์ต ควรลองอ่านฟังก์ชันที่ตัวเองใช้จริง และปรับชื่อข้อความ สี หรือข้อมูลให้ตรงกับสิ่งที่ตัวเองออกแบบและเข้าใจ
